Privacidade

Este site conta como é usado, para sabermos quais guias ajudam e onde as pessoas travam. Ele não usa cookies e não guarda nada que identifique você.

O que é contado

Quais páginas são abertas e em qual idioma; cliques em Baixar e nos links para GitHub, YouTube e Ko-fi; até onde o guia é lido; quais perguntas são abertas; se a busca de atalhos encontrou algo (nunca o que você digitou); e os botões do formulário de feedback.

Como

O Cloudflare Web Analytics conta as visualizações de página, e um pequeno contador nosso, também na Cloudflare, conta o resto. Para contar os visitantes diários, seu endereço IP e seu navegador são misturados com uma chave aleatória que é descartada todo dia; seu endereço IP nunca é guardado. Os dados ficam na Cloudflare por 3 meses e depois são apagados. Só olhamos os totais diários.

Nunca é feito

Nada de publicidade, rastreamento entre sites, gravação de tela ou venda e compartilhamento de dados.

Sua escolha

Se o seu navegador envia Global Privacy Control ou Do Not Track, nada é contado. Você também pode desligar a contagem neste navegador com o botão abaixo. Ele guarda uma única configuração no seu navegador e nada mais.

Downloads

O GitHub conta quantas vezes cada arquivo de versão é baixado. Copiamos esses totais uma vez por dia.

O app WuWa VR

O app não envia dados de uso. Ele só se conecta ao GitHub para procurar atualizações e baixar o mod de VR.

Guardado no seu navegador

Seu idioma e os nomes de botões do controle, se você escolher, para que a próxima página combine. Isso nunca sai do seu navegador.

Outros sites

Os vídeos só tocam a partir de youtube-nocookie.com depois que você escolhe um. GitHub, YouTube e Ko-fi têm suas próprias políticas de privacidade.
