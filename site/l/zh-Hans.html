1.0.7 beta · WuWa 3.7 · Windows x64

进阶选项：便携 ZIP · 上一个测试版 · 10 月 6 日窗口启动兼容性

运行 WuWa-VR-Setup.exe，为当前 Windows 用户安装 WuWa VR，然后打开 WuWa VR 快捷方式。这个小型安装程序不包含 VR 模组：首次点击安装 VR时需要联网下载模组。无需另行安装 Python。

  1. 01 · 游戏。选择库洛启动器或 Steam 安装。应用保留已保存的选择；找到多个安装时请选一个。Steam 版如需手动定位，请选择 Wuthering Waves.exe。你需要自行安装《鸣潮》。
  2. 02 · 安装 VR。阅读并接受账号风险说明，然后安装选中的 VR 版本。已有设置和备份会保留。
  3. 03 · 头显或模拟器。启动头显软件并检查运行时，或选择模拟器。点击 Launch in VR（以 VR 启动）并同意 Windows 授权。Steam 版通过 Steam 启动所选游戏；库洛版需在其启动器中点击开始游戏。

在游戏中，L3 + R3 打开 UEVR 设置。自定义选项位于 VR → WuWa Controls。L3 + A 重置视角中心，L3 + B 显示或隐藏游戏界面。

风险由使用者承担。此非官方模组向游戏注入代码，反作弊可能限制或封禁账号；该项目未经库洛游戏批准。

启动器与 VR 包分别更新

打开第 02 步 → 版本与更新 → 检查更新，选择 Update launcher（更新启动器），下载并校验 1.0.7。游戏、注入器、录制及其他操作均已停止后，选择 Restart to update（重启并更新）并确认。然后在第 02 步版本列表中明确选择 beta-2026-10-06-window-filter 并安装。更新应用会保留原先选中的 VR 包；检查更新不会自动改选新包。安装新包后才会使用本次渲染启动改动。设置、备份、日志和录像保留在原目录；请保留上一个包以便回退。

如果旧启动器阻止更新，请关闭应用，再运行本网站的新 WuWa-VR-Setup.exe。它更新桌面应用，但不能保证卡住的启动任务已经停止。更换 VR 包或运行时前，仍需检查残留进程。

在故障排查 → 卡住的启动器进程中点击查找卡住的启动器进程。逐项查看名称、PID、角色、启动时间、路径和是否允许停止；扫描可能请求管理员权限。默认不勾选任何进程。只选择已验证归属且允许停止的启动器辅助程序或启动任务，再点击停止所选进程并确认列表。游戏、Steam、头显／运行时及注入器进程不属于终止目标。运行时／配置修改、正在录制或无法确认的录制状态仍受保护。查看每项结果，准备好后再明确点击重试连接；恢复操作不会自动重连或启动游戏。无法判断的进程可能需要手动处理；请复制诊断，不要仅凭名称猜测。 如果取消没有得到确认，请在恢复面板核对显示的任务身份。如果辅助程序无法退出，关闭窗口时可明确选择仅关闭启动器窗口；后台任务不会被终止，这不表示任务已经停止。重新安装会保留用户数据，也不会结束已存在的任务。 故障排查 → 准备卸载在确认后清理空闲且已验证的下载文件。Windows 应用卸载也会尝试限时清理。正在使用的 OpenXR 包、忙碌或无法验证的文件、录像、备份和设置会保留；卸载后会打开剩余文件报告，说明具体原因。

选择模拟器或恢复头显会更改系统 OpenXR 运行时，可能需要 Windows 授权。请先关闭游戏和注入器。现在可在没有运行时注册的电脑上明确选择内置模拟器，也可替换旧安装包的模拟器。缺少 Visual C++ 2015–2022 x64 依赖时会显示处理提示。打开或更新应用不会自动选择模拟器。

本测试版的变化

受影响的 Windows 11 Steam 电脑在 1.0.6 中仍未进入 VR，但三个注入 DLL 均已加载。本次修复两个已复现的窗口过滤缺陷：工作线程可能在空闲时退出，窗口标题查询可能造成渲染线程死锁。标题查询现在有超时限制，且在过滤锁之外执行。启动状态会区分正常图形预热和实际故障，并在当前后端关闭时停止等待。每次启动的图形钩子记录现在可区分未收到回调和窗口被拒绝。这些修复已通过后台测试；受影响电脑的启动及头显体验仍未验证。

Suppress mismatched NPC rim lighting（抑制双眼不一致的 NPC 轮廓光）位于 VR → WuWa Controls，默认关闭。它抑制在已测试 NPC 场景中产生额外亮边的卡通轮廓光，也会移除附近使用该效果的角色原有轮廓光。关闭选项时，若该值仍由此功能管理，将恢复先前值。底层双眼渲染问题尚未解决。

场景／对话加载停顿、HUD 比例刷新不可靠、平面菜单背景随头部移动等问题仍未解决，菜单可暂用手动单目影院。武器／声骸子菜单反射、远处 NPC 轮廓光、部分雾气／特效及完整动画第一人称瞄准仍需完善。受影响的 Steam 电脑尚未通过本候选版本的渲染启动测试。如果启动一直等待，请使用故障排查 → 复制诊断，不要再启动另一个注入器。Epic 注入及本版头显验收尚未完成。

两种手动屏幕模式：先按住 LT + RT，再点击 R3 切换单目影院（两眼显示相同场景与 HUD），或按住 L3 0.8 秒切换立体屏幕。重复前松开全部按键，并关闭 UEVR 与 HUD／鼠标调整。自动影院仍为实验功能，默认关闭；最近报告的引擎内过场未触发自动切换，真正的预渲染影片也未测试。请保留手动快捷键作为备用。

进阶选项：便携 ZIP

便携 ZIP 是进阶备用方式：完整解压，保持 app 和 python 文件夹完整，然后打开 WuWa VR Launcher.exe。它使用旧版浏览器界面，不会安装或自动更新桌面应用。建议新用户使用安装程序。

舒适度与恢复

在 HUD placement and visibility 中选择跟随视线的 HUD，一起调整大小与距离，或让它适配可选窗口。L3 + B 可恢复被隐藏的菜单；L3 + A 可重置视角中心。新提供的配置默认显示快捷键表，L3 + Menu 可隐藏。已有的个人设置会保留。

仍待完善的问题

请使用所选版本附带的设置；不同版本的 Native Stereo Fix 默认值不同。较新包中的 BUILD GUIDE.html 列出了这些值。双眼的反射、可见性和光照差异，以及完整动画模式下的瞄准仍在测试中。候选修复尚未在所有场景中确认。没有全局暂停时间功能。
