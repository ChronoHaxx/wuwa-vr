ダウンロード

プライバシー

このサイトは、どのガイドが役に立ち、どこでつまずくかを知るために利用状況を数えています。Cookie は使わず、あなたを識別する情報も保存しません。

数えている内容

開かれたページとその言語、「ダウンロード」と GitHub・YouTube・Ko-fi へのリンクのクリック、ガイドをどこまで読んだか、開かれた質問、ショートカット検索で結果が見つかったかどうか（入力した文字は記録しません）、フィードバックフォームのボタンです。

数え方

ページの閲覧数は Cloudflare Web Analytics が数え、それ以外は同じく Cloudflare 上で動く小さな自作カウンターが数えます。1 日の訪問者数を数えるため、IP アドレスとブラウザーの情報を、毎日破棄されるランダムな鍵と混ぜ合わせます。IP アドレスは保存しません。データは Cloudflare に 3 か月保存されたあと削除されます。見るのは 1 日ごとの合計だけです。

決して行わないこと

広告、サイトをまたいだ追跡、画面の録画、データの販売や共有は行いません。

あなたの選択

ブラウザーが Global Privacy Control または Do Not Track を送信している場合、何も数えません。下のボタンで、このブラウザーでの計測をオフにすることもできます。ブラウザーに設定を 1 つ保存するだけで、それ以外は何も保存しません。

ダウンロード

GitHub は各リリースファイルのダウンロード回数を数えています。その合計を 1 日 1 回コピーしています。

WuWa VR アプリ

アプリは利用データを送信しません。アップデートの確認と VR Mod のダウンロードのために GitHub に接続するだけです。

ブラウザーに保存されるもの

言語とコントローラーのボタン表記を選んだ場合、その選択を保存し、次のページでも同じ表示にします。この情報がブラウザーの外に出ることはありません。

ほかのサイト

動画は、あなたが選んだときにだけ youtube-nocookie.com から再生されます。GitHub、YouTube、Ko-fi にはそれぞれのプライバシーポリシーがあります。
