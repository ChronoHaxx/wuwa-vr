# Help make WuWa VR better

This is a free, unofficial fan project. You do not need to donate, write code or
speak English to help: bug reports, translations, comfort feedback and small
fixes all count. Volunteers are welcome; replies and continued maintenance are
not guaranteed.

## Report something

Use the website's [feedback form](https://chronohaxx.github.io/wuwa-vr/feedback.html)
for a bug, feature, accessibility or language request, in any language. It
prepares a GitHub issue for you to review and submit; it never posts by itself.
Leave out account IDs, personal paths, passwords and unreviewed logs.

## Translations

The whole website is available in ten languages. Each language has a translation
memory, `dev/i18n/<lang>.json`, mapping every English paragraph to its
translation. To fix a translation, edit the `"t"` text of that entry and keep
any HTML tags, links and button names (`L3 + R3`, `WuWa Controls`) as they are.
When English text changes, its old translation no longer matches and that
paragraph shows in English until it is translated again. See
[dev/i18n/README.md](https://github.com/ChronoHaxx/wuwa-vr/blob/main/dev/i18n/README.md).

## Code, forks and sharing

Keep a fix small, describe the actual problem and how you checked it, and say
whether you tested it in the game and headset. Keep existing attribution. Our
[scoped license](LICENSE.md) covers original work only; do not relicense
upstream code or publish private game data.

Forks of the MIT-covered parts are welcome. Please keep access free, share
improvements and avoid paid repacks or paywalled forks. That is a community
request, not an MIT condition: MIT allows commercial use.
