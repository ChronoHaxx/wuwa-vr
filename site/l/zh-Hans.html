安装后，只需三步

下载测试版安装程序 · Windows EXE 更新说明与源代码

1.0.1 beta · WuWa 3.7 · Windows x64

进阶选项：便携 ZIP · 上一测试版 · 10 月 4 日启动器版

运行 WuWa-VR-Setup.exe，为当前 Windows 用户安装 WuWa VR，然后打开 WuWa VR 快捷方式。这个小型安装程序不包含 VR 模组：首次点击安装 VR时需要联网下载约 54 MB。无需另行安装 Python。

  1. 01 · 游戏。检查自动找到的官方游戏启动器，或手动选择其位置。你需要自行安装《鸣潮》。
  2. 02 · 安装 VR。阅读并接受账号风险说明，然后安装选中的 VR 版本。已有设置和备份会保留。
  3. 03 · 头显或模拟器。启动头显软件并检查显示的运行时，或主动选择模拟器。点击 Launch in VR（以 VR 启动），允许 Windows 权限请求，然后在官方游戏启动器中点击 Play（开始游戏）。

在游戏中，L3 + R3 打开 UEVR 设置。自定义选项位于 VR → WuWa Controls。L3 + A 重置视角中心，L3 + B 显示或隐藏游戏界面。

风险由使用者承担。此非官方模组向游戏注入代码，反作弊可能限制或封禁账号；该项目未经库洛游戏批准。

启动器与 VR 包分别更新

打开第 02 步 → 版本与更新 → 检查更新。桌面应用：选择 Update launcher（更新启动器）以下载并校验更新；此时不会重启应用。更新就绪后，关闭游戏和注入器，停止录制并完成其他操作，再选择 Restart to update（重启并更新）并确认。安装或更新桌面应用会保留当前选择的 VR 包。VR 包：在第 02 步选择 beta-2026-10-04-cinematic 并安装（已安装时直接选用），即可使用 cinematic-20261004。设置、备份、日志和录像保留在原有数据文件夹中，旧 VR 包仍可用于回退。

选择模拟器或恢复头显运行时会更改系统 OpenXR 运行时，可能需要 Windows 权限确认。请先关闭游戏和注入器。仅打开或更新应用不会自动切换到模拟器。

本测试版的变化

过场构图现在采用同一镜头决策，同时保留双眼各自的立体视图。作者已确认私测 screen-comfort-r1 的模拟器回放改善；最新 68 秒录像的抽样画面中，两眼黑边高度一致。此修正默认开启，头显舒适度仍待验证。此前已接受的远处植被、间接光照、共鸣者主页面反射、大招镜头及二维亮度修正继续保留。

Suppress mismatched NPC rim lighting（抑制双眼不一致的 NPC 轮廓光）位于 VR → WuWa Controls，默认关闭。它抑制在已测试 NPC 场景中产生额外亮边的卡通轮廓光，也会移除附近使用该效果的角色原有轮廓光。关闭选项时，若该值仍由此功能管理，将恢复先前值。底层双眼渲染问题尚未解决。

部分场景／对话加载停顿、HUD 比例刷新不可靠、平面菜单背景仍随头部移动等问题尚未解决。菜单可暂时手动切换到单目影院。武器／声骸子菜单反射、远处 NPC 轮廓光和完整动画第一人称瞄准仍需完善；Steam／Epic 游戏版本注入与全新电脑安装也未验证。

两种手动屏幕模式：先按住 LT + RT，再点击 R3 切换单目影院（两眼显示相同场景与 HUD），或按住 L3 0.8 秒切换立体屏幕。重复前松开全部按键，并关闭 UEVR 与 HUD／鼠标调整。自动影院仍为实验功能，默认关闭；最近报告的引擎内过场未触发自动切换，真正的预渲染影片也未测试。请保留手动快捷键作为备用。

进阶选项：便携 ZIP

便携 ZIP 是进阶备用方式：完整解压，保持 app 和 python 文件夹完整，然后打开 WuWa VR Launcher.exe。它使用旧版浏览器界面，不会安装或自动更新桌面应用。建议新用户使用安装程序。

Xbox 常用快捷键

L3 / R3 表示按下摇杆。View 是双矩形键，Menu 是三横线键。LB + Y 保持游戏原有功能。

舒适度与恢复

在 HUD placement and visibility 中选择跟随视线的 HUD，一起调整大小与距离，或让它适配可选窗口。L3 + B 可恢复被隐藏的菜单；L3 + A 可重置视角中心。新提供的配置默认显示快捷键表，L3 + Menu 可隐藏。已有的个人设置会保留。

仍待完善的问题

请使用所选版本附带的设置；不同版本的 Native Stereo Fix 默认值不同。较新包中的 BUILD GUIDE.html 列出了这些值。双眼的反射、可见性和光照差异，以及完整动画模式下的瞄准仍在测试中。候选修复尚未在所有场景中确认。没有全局暂停时间功能。
