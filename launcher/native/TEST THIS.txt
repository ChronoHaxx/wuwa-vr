    a deliberately selected older package until you choose the new package.

    with a recovery message. Close game/injector, choose Use bundled simulator,
    accept Windows permission, then verify the current package is ready.
    A valid headset runtime should also enable launch without auto-switching.
[ ] Launch once using the intended Steam/Kuro route. Confirm actual VR remains
    running, open UEVR, then exit normally. Copy diagnostics if startup fails.

    Verify L3+R3 menu, L3+Cross recenter, L3+Circle HUD, L2+R2 then R3 mono,

    Check USB/Bluetooth only if available. Record which connection was tested.
[ ] Hold a shortcut during Alt-Tab/disconnect, then return/reconnect. No toggle
    should happen until controls are released and pressed again. If using
    Steam Input, each chord should toggle once, not once per input path.
    Direct HID does not consume the game's own native PlayStation input.
[ ] Check ordinary Xbox use still works if available. Test headset comfort
    separately; stop if uncomfortable. Roll back when idle only if needed.
