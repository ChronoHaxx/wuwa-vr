Бесплатный неофициальный фанатский VR-проект для Wuthering Waves. Играйте с геймпадом Xbox и настройте удобный вид и HUD.

Основные элементы лаунчера и эта инструкция переведены. Часть описаний сборок, инструменты разработчика и диагностические ошибки остаются на английском. Переводы предварительные; язык игры и UEVR не меняется.

Начало работы

  1. Распакуйте весь ZIP в обычную папку и откройте WuWa VR Launcher.exe. Папки app и python должны оставаться рядом. Устанавливать Python отдельно не нужно.
  2. Подключите шлем и запустите его ПО. Для симулятора закройте WuWa и инжектор, затем выберите «Использовать симулятор из этого пакета». Изменение системной среды OpenXR требует разрешения Windows и действует со следующего запуска игры.
  3. Прочитайте и примите предупреждение, выберите сборку и нажмите «Применить и запустить». Разрешите внедрение кода в запросе Windows и нажмите «Играть» в лаунчере игры. Проверен отдельный официальный лаунчер; внедрение в версии Steam/Epic не подтверждено.
  4. L3 + R3 открывает UEVR. L3 + B показывает/скрывает HUD и меню; L3 + A центрирует вид; L3 + Menu показывает подсказку; L3 + LB переключает режим HUD/мыши. Перед игровыми сочетаниями закройте настройки UEVR.

Основные сочетания Xbox

L3 / R3 — нажатия на стики. View — кнопка с двумя прямоугольниками, Menu — с тремя линиями. LB + Y сохраняет обычное действие игры.

Комфорт и восстановление

В HUD placement and visibility выберите HUD, следующий за взглядом, настройте вместе размер и расстояние или впишите его в необязательное окно. L3 + B возвращает скрытое меню, L3 + A центрирует вид. Новый профиль показывает памятку по умолчанию; L3 + Menu скрывает её. Сохранённые настройки сохраняются.

Нерешённые проблемы

Используйте настройки вашей сборки: значения Native Stereo Fix по умолчанию различаются между выпусками. В новых пакетах они указаны в BUILD GUIDE.html. Отражения, различия видимости и освещения между глазами, а также прицеливание с полной анимацией ещё проверяются. Исправления не подтверждены для всех сцен. Глобальной остановки времени нет.

Бесплатный фанатский проект сообщества

Оригинальный сайт, руководства и явно перечисленные независимые части используют MIT. UEVR, скрипты сообщества и контент игры сохраняют свои условия; мод целиком не под MIT. Форки и вклад приветствуются в рамках соответствующих лицензий.
