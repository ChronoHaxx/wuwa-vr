Install, then three steps

Download beta installer · Windows EXE Release notes & source

1.1.1 beta · WuWa 3.7 · Windows x64

Advanced: portable ZIP · Previous beta · 1.1.0

Run WuWa-VR-Setup.exe to install WuWa VR for your Windows user, then open the WuWa VR shortcut. This small installer does not include the VR mod: the first Install VR needs internet to download it. No separate Python installation is needed.

  1. 01 · Game. Choose your Kuro or Steam installation. A saved choice is kept; if several installations are found, choose one. For Steam, browse to Wuthering Waves.exe if needed. You need your own copy of the game.
  2. 02 · Install VR. Read and accept the account-risk notice, then install the selected VR version. Existing settings and backups are kept.
  3. 03 · Headset or simulator. Start your headset software and select its valid runtime, or explicitly choose the bundled simulator. Once the runtime is ready, select Launch in VR and accept Windows permission. Steam starts through Steam; for Kuro, press Play in its launcher.

In game, L3 + R3 opens UEVR settings. Custom options are under VR → WuWa Controls. L3 + A / Cross recenters; L3 + B / Circle shows or hides the game UI. Xbox and PlayStation controls and limitations.

Use at your own risk. This unofficial mod injects into the game; anti-cheat may restrict or ban an account. It is not approved by Kuro Games.

Keep WuWa VR updated

The Launcher app and VR package have separate status. Update the app to 1.1.1, then choose 1.1.1 beta in step 02 and install it. The app update keeps your package choice, including a deliberate rollback. Check updates refreshes availability; it does not install or switch anything.

Recovery and runtime details

If the old launcher blocks its update, close the app and use the new WuWa-VR-Setup.exe from this website. This installs the app update; it does not guarantee that a stalled startup worker has stopped. Review remaining processes before changing the VR package or runtime.

In Troubleshooting → Stuck launcher processes, choose Find stuck launcher processes. Review each name, PID, role, start time, path and eligibility; elevation may be requested. Nothing is selected automatically. Choose an eligible verified launcher helper or startup worker, then use Stop selected and confirm the listed processes. Game, Steam, headset/runtime and injector processes are not termination targets. Runtime/profile changes and active or unknown recording state remain protected. Review each result, then explicitly choose Retry connection when ready; recovery does not reconnect or launch the game automatically. An inconclusive process may require manual handling; copy diagnostics instead of guessing from its name. If cancellation is not acknowledged, review the shown worker identity in recovery. If Close cannot shut down the helper, Close launcher only offers an explicit way to exit the window while leaving background work untouched; it is not a claim that the worker stopped. Reinstalling preserves user data and does not end existing workers. Troubleshooting → Prepare uninstall removes verified downloads after confirmation when idle. Windows Apps uninstall also attempts bounded cleanup. Active OpenXR packages, busy or unverified files, recordings, backups and settings are retained. Any remaining-file report opens after uninstall with exact reasons.

Launch is available only with a valid headset runtime or the simulator from your selected installed VR package. If Windows still points at an older simulator, choose Use bundled simulator after closing the game and injector. Runtime switching is explicit and may ask for Windows permission; opening or updating the app never changes it automatically.

Version 1.1.1 beta

The user confirmed 1.0.10 startup on the previously affected Windows 11 Steam simulator PC, and 1.1.0 through Kuro on the owner's PC. The owner's 1.1.0 Steam route crashed. Version 1.1.1 repairs the resize recursion found in that crash dump; controlled graphics and launcher tests pass, but this repair still needs real Steam and headset testing.

Scene/dialogue loading stalls, unreliable HUD-aspect refresh and moving backgrounds behind flat menus remain open. Manual mono theatre can help with menus. Some NPC lighting, reflections and fog/VFX still need testing. Automatic cinematic switching is experimental, off by default, and untested with a real prerendered movie. Epic injection and broad headset compatibility remain unverified.

Rendering and cinematic caveats

Suppress mismatched NPC rim lighting is under VR → WuWa Controls and starts off. It suppresses the toon-rim effect that produced extra bright contours in the tested NPC scene. It also removes that intended effect from nearby characters that use it. Turning it off restores the prior value if the workaround still owns it. The underlying stereo rendering fault is unresolved.

Two manual screen modes: fully hold LT + RT first, then click R3 for mono theatre (the same scene and HUD for both eyes), or hold L3 for 0.8 seconds for a stereoscopic screen. Release all controls before repeating, with UEVR and HUD/mouse adjustment closed. Automatic cinema is experimental and off by default: it did not activate for the latest reported in-engine scene, and an actual prerendered movie has not been tested. Keep the manual shortcut available.

Advanced: portable ZIP

The portable ZIP is an advanced fallback: extract the whole archive, keep its app and python folders together, and open WuWa VR Launcher.exe. It uses the older browser interface and does not install or self-update the desktop app. The installer is the recommended starting point.

Everyday Xbox controls

L3 / R3 mean pressing the sticks. View is the two-squares button; Menu is the three-lines button. LB + Y stays the game's normal action.

Comfort and recovery

In HUD placement and visibility, choose a following HUD, adjust size and distance together, or fit it to the optional portal. L3 + B restores a hidden menu. L3 + A recenters your view. The sheet starts enabled in the new supplied profile; L3 + Menu hides it. Existing saved choices are respected.

What still needs work

Use the settings supplied with your build; Native Stereo Fix defaults differ between releases. BUILD GUIDE.html in newer packages lists those values. Reflections, visibility and lighting differences between eyes, and full-animation aiming remain under test. Candidate fixes are not confirmed for every scene. No global time pause is implemented.
