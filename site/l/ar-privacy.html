تنزيل

الخصوصية

يحصي هذا الموقع طريقة استخدامه لنعرف أي الأدلة تفيد وأين يتعثر الناس. لا يستخدم ملفات تعريف الارتباط (cookies) ولا يحفظ أي شيء يعرّف بك.

ما الذي يُحصى

الصفحات التي تُفتح وبأي لغة؛ والنقر على «تنزيل» وعلى روابط GitHub وYouTube وKo-fi؛ وإلى أي حدّ يُقرأ الدليل؛ والأسئلة التي تُفتح؛ وهل وجد البحث عن الاختصارات نتيجة (دون تسجيل ما كتبته أبدًا)؛ وأزرار نموذج الملاحظات.

كيف

تحصي Cloudflare Web Analytics مشاهدات الصفحات، ويحصي عدّادٌ صغير خاص بنا، يعمل أيضًا على Cloudflare، الباقي. لإحصاء الزوار اليوميين، يُمزج عنوان IP الخاص بك ومتصفحك بمفتاح عشوائي يُتخلّص منه كل يوم؛ ولا يُحفظ عنوان IP أبدًا. تبقى البيانات لدى Cloudflare ثلاثة أشهر ثم تُحذف. ولا يُنظر إلا إلى المجاميع اليومية.

ما لا نفعله أبدًا

لا إعلانات، ولا تتبّع عبر المواقع، ولا تسجيل للشاشة، ولا بيع للبيانات أو مشاركتها.

اختيارك

إذا كان متصفحك يرسل Global Privacy Control أو Do Not Track فلا يُحصى شيء. ويمكنك أيضًا إيقاف الإحصاء في هذا المتصفح بالزر أدناه. يحفظ إعدادًا واحدًا في متصفحك ولا شيء غيره.

التنزيلات

يحصي GitHub عدد مرات تنزيل كل ملف من ملفات الإصدار. ونحن ننسخ هذه المجاميع مرة واحدة يوميًا.

تطبيق WuWa VR

لا يرسل التطبيق أي بيانات استخدام. يتصل بـ GitHub فقط للتحقق من التحديثات وتنزيل مود الواقع الافتراضي.

ما يُحفظ في متصفحك

لغتك وأسماء أزرار يد التحكم إن اخترتها، لتطابقها الصفحة التالية. ولا يغادر ذلك متصفحك أبدًا.

مواقع أخرى

لا تُشغَّل الفيديوهات من youtube-nocookie.com إلا بعد أن تختار أحدها. ولكلٍّ من GitHub وYouTube وKo-fi سياسة خصوصية خاصة به.

لديك أسئلة؟ افتح بلاغًا (issue) على GitHub
