Code and contributions

Browse GitHubFork the repositorySearch issuesPrepare a report

The repository holds the website, the launcher and the mod's source changes. It is an overlay on pinned upstream versions, not a standalone UEVR fork: mod/BUILD.md explains how to rebuild. Each release tag records the exact source of that download.

Folder Contents
mod/uevr Native changes: stereo, UI, camera, game-version checks
mod/lua Camera, controller, head-hiding and shadow scripts
mod/localization In-game control and shortcut-sheet translations
launcher/dev Portable launcher, recorder and test/measurement tools
site, docs, dev Website, player docs and their generators

The explainer has a file-by-file map, the stereo fixes and how they were found. When changing rendering, keep each eye's own projection and history; never copy one eye's finished image into the other. Check a rendering change with a capture of the affected scene, not only a successful build.

Build natively with bounded parallelism on modest PCs: cmake --build out/build/x64-RelWithDebInfo --config RelWithDebInfo --target uevr --parallel 1 -- /p:CL_MPCount=1 /p:MultiProcMaxCount=1. A new DLL needs a game restart.

Contributing

This is a free, unofficial fan project. You do not need to donate, write code or speak English to help: bug reports, translations, comfort feedback and small fixes all count. Volunteers are welcome; replies and continued maintenance are not guaranteed.

Report something

Use the website's feedback form for a bug, feature, accessibility or language request, in any language. It prepares a GitHub issue for you to review and submit; it never posts by itself. Leave out account IDs, personal paths, passwords and unreviewed logs.

Translations

The whole website is available in ten languages. Each language has a translation memory, dev/i18n/<lang>.json, mapping every English paragraph to its translation. To fix a translation, edit the "t" text of that entry and keep any HTML tags, links and button names (L3 + R3, WuWa Controls) as they are. When English text changes, its old translation no longer matches and that paragraph shows in English until it is translated again. See dev/i18n/README.md.

Code, forks and sharing

Keep a fix small, describe the actual problem and how you checked it, and say whether you tested it in the game and headset. Keep existing attribution. Our scoped license covers original work only; do not relicense upstream code or publish private game data.

Forks of the MIT-covered parts are welcome. Please keep access free, share improvements and avoid paid repacks or paywalled forks. That is a community request, not an MIT condition: MIT allows commercial use.
