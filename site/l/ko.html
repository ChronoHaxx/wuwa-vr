익숙한 언어로 시작하세요

무료 비공식 명조 VR 팬 프로젝트입니다. Xbox 컨트롤러를 그대로 사용하고 편안한 시점과 HUD를 설정하세요.

런처의 주요 조작과 이 설정 안내는 번역되었습니다. 일부 빌드 설명, 개발 도구, 진단 오류는 영어입니다. 번역은 초안이며 게임이나 UEVR 언어를 바꾸지 않습니다.

시작하기

  1. ZIP 전체를 일반 폴더에 압축 해제한 뒤 WuWa VR Launcher.exe를 여세요. app과 python 폴더를 같은 위치에 유지하세요. Python을 따로 설치할 필요는 없습니다.
  2. 헤드셋을 연결하고 해당 소프트웨어를 시작하세요. 시뮬레이터를 사용하려면 게임과 인젝터를 닫고 ‘이 패키지의 시뮬레이터 사용’을 선택하세요. 시스템 OpenXR 변경에는 Windows 권한 승인이 필요하며 다음 게임 실행부터 적용됩니다.
  3. 위험 안내를 읽고 동의한 뒤 빌드를 선택하고 ‘적용 및 실행’을 누르세요. 코드 삽입을 위한 Windows 권한을 허용하고 게임 런처에서 플레이를 누르세요. 독립 공식 런처로 확인했으며 Steam/Epic 버전 삽입은 검증되지 않았습니다.
  4. L3 + R3: UEVR 설정. L3 + B: HUD와 메뉴 표시/숨기기. L3 + A: 시점 중앙 재설정. L3 + Menu: 단축키 안내. L3 + LB: HUD/마우스 모드 전환. 게임 단축키를 사용하기 전에 UEVR 설정을 닫으세요.

편안한 설정과 복구

HUD placement and visibility에서 시선을 따르는 HUD를 고르고 크기와 거리를 함께 조절하거나 선택적 창에 맞추세요. L3 + B로 숨긴 메뉴를 복원하고 L3 + A로 중앙을 재설정합니다. 새 제공 설정은 단축키 표를 기본 표시하며 L3 + Menu로 숨깁니다. 기존 저장 설정은 유지됩니다.

남아 있는 문제

사용하는 빌드에 포함된 설정을 따르세요. Native Stereo Fix 기본값은 릴리스마다 다릅니다. 새 패키지의 BUILD GUIDE.html에서 값을 확인할 수 있습니다. 양쪽 눈의 반사, 가시성, 조명 차이와 전체 애니메이션 모드의 조준은 아직 테스트 중입니다. 수정 후보가 모든 장면에서 검증된 것은 아닙니다. 전역 시간 정지는 없습니다.

무료 팬 프로젝트, 함께 만드는 개선

독자적인 웹사이트, 가이드와 명시된 독립 작업에는 MIT 라이선스가 적용됩니다. UEVR, 커뮤니티 스크립트, 게임 콘텐츠는 각자의 조건을 따릅니다. 모드 전체가 MIT는 아닙니다. 허용된 범위에서 포크와 기여를 환영합니다.

무료 접근을 유지하고 제작자를 표시하며 개선을 공유해 주세요. 재포장 판매나 커뮤니티 포크 유료화는 지양해 주세요. 이는 요청이지 MIT에 추가한 제한이 아닙니다. MIT는 상업적 사용과 판매를 허용합니다.

선택적인 후원

후원할 의무는 없습니다. 영구 유지보수, 업데이트, 개인 지원이나 호환성 보장을 기대한다면 후원하지 마세요. 여가 시간의 취미이므로 중단하거나 종료할 수 있습니다. 후원은 현재 작업에 대한 지원이며 대가를 약속하지 않습니다. GPU 업그레이드는 로컬 오픈 웨이트 모델 실험과 모드 VR에 도움이 됩니다.
