Play WuWa in VR

1.1.0 player guide · Wuthering Waves 3.7 · Windows PCVR

Install WuWa-VR-Setup.exe, then open the WuWa VR shortcut. No separate Python installation is needed. The first VR-package installation needs internet; the small Setup download contains the launcher app.

01 · Choose your game

Check the detected or saved location. Use Change to select Steam or the official Kuro launcher. If browsing for Steam, choose its Wuthering Waves.exe, not the inner Shipping executable. Choose explicitly if you have several installations.

02 · Install WuWa VR

Check the target game version, read the account-risk notice and select Install VR. The package is verified before installation. Installing does not start the game.

Launcher app is this desktop window. VR package is the mod and its tools. Updating one does not automatically update the other.

03 · Choose the runtime, then launch

Start your headset software and select Use headset, or choose Use bundled simulator for a desktop preview. Launch requires a valid headset runtime or the valid simulator belonging to the selected VR package. An old package’s simulator must be replaced or the headset runtime selected first.

Runtime changes are explicit, may request Windows permission and require WuWa and its injector to be closed. Opening, installing or updating the launcher does not change the runtime automatically.

Select Launch in VR and accept Windows permission when requested. Steam starts the selected game through Steam; with Kuro, press Play in its launcher. Later visits retain your choices.

Unofficial community mod, not approved by Kuro Games. Injection may trigger anti-cheat or account restrictions. Review and accept the notice before proceeding.

Updates and rollback

Open 02 → Versions & updates → Check updates. Update the launcher app when offered, then use Restart to update when idle. Select and install the desired VR package separately. A failed update check or cached list does not establish that your package is current.

This release pairs app 1.1.0 with package beta-1-1-0, build player-ready-1-1-0, for WuWa 3.7. To undo a VR-package update, close the game and injector, stop recording, then use Troubleshooting → Repair & recovery → Use previous installed version. This does not roll back the launcher app. Settings, backups and recordings are retained.

If app updating is blocked, use the latest Setup from the website. Reinstalling does not stop an existing stuck worker; use recovery below first.

Portable fallback

Download WuWa-VR-Launcher.zip from the matching release, extract everything and open WuWa VR Launcher.exe. Keep its folders together. This opens the separate web tool interface; it does not self-update the installed desktop app. The launcher’s Open matching portable ZIP action locates an already available verified copy.

Everyday controls

Xbox / XInput is the normal gameplay path. L3 / R3 mean click the sticks. Focus the game, close UEVR and HUD/mouse adjustment, and release controls between shortcuts. Physical gamepad passthrough bypasses mod shortcuts. Insert opens UEVR with the keyboard.

InputAction
L3 + R3Open or close UEVR settings
Hold both LT + RT first, then click R3Mono theatre: identical scene and HUD for both eyes; useful for troublesome menus and cutscenes
Hold both LT + RT first, then hold L3 for 0.8 secondsStereoscopic screen: a screen view with depth
Hold L3, then fully squeeze LT / RTPortal / temporary 10× diorama. Keep the other trigger released; use outside game menus. F7 also toggles the portal.
L3 + A / BRecenter / show or hide game UI
L3 + View / MenuFirst person / shortcut sheet

PS4/PS5: Steam Input or another working Xbox/XInput mapping uses the same shortcuts. Cross/Circle/Square/Triangle map to A/B/X/Y, L1/R1 to LB/RB, L2/R2 to LT/RT, Share/Create to View, and Options to Menu.

1.1.0 adds experimental direct input for Sony DualShock 4 and DualSense/Edge over USB or Bluetooth, after two seconds without a successful XInput pad poll. Any active XInput pad takes priority. Release all controls after a reconnect or input-source change, and check VR → WuWa Controls → Controller shortcuts. Direct input can open/close UEVR, but menu navigation still needs keyboard/mouse, mapped XInput or existing VR menu controls. Direct input cannot suppress those buttons in the game’s own native input path, so a shortcut may also trigger a game action; XInput mapping is preferred for consumed shortcuts. No touchpad/PS-button shortcut, rumble or adaptive-trigger support is added. Physical PS testing remains pending. See the full reference.

Open VR → WuWa Controls → View modes and cutscenes for screen choices. Cinematic framing correction is on by default. Automatic switching is experimental and off: a reported in-engine scene did not switch, and prerecorded-movie switching is untested. Keep the manual theatre shortcut available.

Optional walking, diorama and hand demos

VR controllers for walking (optional) → Walking input starts off. OpenXR is required. Wake both Quest controllers, focus the game, release all buttons/triggers/grips and center the sticks to arm. Repeat after focus loss or reconnect.

VR controllers only supplies slot 0. A VR + treadmill / Xbox slot mode preserves that chosen device’s movement while adding VR buttons and look. Check its slot in Troubleshooting → Controller check; the number alone cannot identify RealityRunner. First person is a separate choice. This sightseeing layout is incomplete for combat; see the walking reference.

Diorama needs Native Stereo and temporarily enlarges head movement with the world scale; turning it off restores your normal scale. The optical hand/finger demo is visualization only, without grabbing, collision or gesture gameplay. These options start off; physical-headset acceptance remains pending.

If something goes wrong

  • Startup stuck: use Stop waiting. If cancellation is not confirmed, open Troubleshooting → Stuck launcher processes → Find stuck launcher processes. Review identities and eligibility, select only the worker you intend to stop, then confirm Stop selected. Nothing is preselected. Review results before choosing Retry connection.
  • Cannot close: Close launcher only closes the window while leaving background work untouched. It does not clear a startup lock. Recovery never targets WuWa, Steam, the injector or a VR runtime for termination; recording and runtime/profile changes remain protected.
  • Controller missing: Controller check reads XInput slots and HidHide information without changing settings. A connected slot is not proof of in-game button delivery. Keep intentional treadmill/remapper setups intact.
  • Squashed HUD: try VR → WuWa Controls → Reset HUD aspect and read its status; it can be unavailable. Opening and closing ESC has helped when the game permits it. L3 + B restores hidden game UI.
  • Report a problem: use Copy diagnostics and Report an issue. Include the app and VR-package versions, what happened and a recording if available.
Removing downloaded versions or uninstalling

Troubleshooting → Prepare uninstall cleans verified downloads after confirmation when idle, then use Windows Settings → Apps to uninstall the app. The game, settings, backups, recordings, active OpenXR package and busy/unverified files are kept. Review the cleanup report for retained files. Windows uninstall also attempts bounded cleanup; reinstalling is not a substitute for stopping a stuck worker.

Recording and current limits

The Developer tools footer link opens the selected package’s web tools for recording, playtests and logs. Recording supports SteamVR and the bundled simulator; this recorder does not support VDXR or audio. Review videos for player names and account details before sharing. See the feedback guide.

Startup on the affected Windows 11 Steam PC with the simulator was confirmed by the user on 1.0.10. This does not establish 1.1.0 PS4/PS5 or physical-headset acceptance; those checks remain pending.

Known issues include long scene/dialogue stalls, unreliable HUD refresh, moving flat-menu backgrounds, distant NPC rim-light mismatch, Weapon/Echo submenu reflections and full-animation first-person aim. Manual mono theatre helps some menus/cinematics. Optional rim suppression removes intended nearby rim lighting too; it is a workaround, not a shader repair. The mod retains game graphics choices and custom edits; recognized inherited overrides are cleaned only during the documented package upgrade.

开始体验鸣潮 VR

1.1.0 玩家指南 · 鸣潮 3.7 · Windows PCVR

运行 WuWa-VR-Setup.exe 后打开 WuWa VR 快捷方式，无需另装 Python。小型 Setup 只安装启动器应用；首次安装 VR 模组包需要联网下载。

01 · 选择游戏

确认自动找到或已保存的路径。点击更改选择 Steam 或库洛官方启动器。手动选择 Steam 时，请选 Wuthering Waves.exe，而不是内部 Shipping 文件。多个安装并存时请明确选择。

02 · 安装鸣潮 VR

确认对应游戏版本，阅读账号风险提示，再点击安装 VR。安装前会校验下载包；安装不会启动游戏。

启动器应用是这个桌面窗口；VR 模组包包含模组及工具。更新其中一个不会自动更新另一个。

03 · 选择运行时，再启动

启动头显连接软件后选择使用头显，或选择使用内置模拟器进行桌面预览。启动要求有效的头显运行时，或属于当前所选 VR 包的有效模拟器。旧包的模拟器需先切换为当前内置版本，或改用头显运行时。

运行时切换需明确操作，可能请求 Windows 管理员授权，并要求先关闭游戏和注入器。打开、安装或更新启动器不会自动切换运行时。

点击以 VR 模式启动并在需要时确认 Windows 授权。Steam 版通过 Steam 启动；库洛版还需在官方启动器点击开始。下次会保留你的选择。

这是未经库洛游戏认可的非官方社区模组。注入可能触发反作弊或账号限制。请先阅读并接受风险提示。

更新与回退

打开第 02 步 → 版本与更新 → 检查更新。先按提示更新启动器，空闲时选择重启并更新；再单独选择并安装所需的VR 模组包。检查失败或使用缓存列表时，不能据此判断已是最新版。

本版本配套：应用 1.1.0，包 beta-1-1-0，构建 player-ready-1-1-0，游戏 3.7。回退 VR 包前关闭游戏和注入器、停止录制，再用故障排查 → 修复与恢复 → 使用上一个已安装版本。这不会回退桌面应用；设置、备份和录像会保留。

应用无法更新时，可使用网站上的新版 Setup。重装不会停止已有的卡住进程，请先使用下方恢复功能。

便携备用方式

从同一发布页面下载 WuWa-VR-Launcher.zip，完整解压后打开 WuWa VR Launcher.exe，并保留所有文件夹。这是独立网页工具界面，不会自动更新已安装的桌面应用。打开匹配的便携 ZIP可定位已下载且校验通过的对应包。

常用控制

通常使用 Xbox／XInput 游戏输入。L3／R3表示按下左右摇杆。将焦点切回游戏、关闭 UEVR 与 HUD／鼠标调整，再使用快捷键；重复操作前松开所有按键；手柄直通会绕过模组快捷键。键盘 Insert 可打开 UEVR。

输入操作
L3 + R3开关 UEVR 设置
先按住 LT + RT，再点击 R3单目影院：双眼显示相同场景与 HUD，可用于异常菜单或过场
先按住 LT + RT，再按住 L3 0.8 秒立体屏幕：保留场景深度
按住 L3，再按到底 LT／RT空间窗口／临时 10 倍微缩视角。另一扳机保持松开，在游戏菜单外操作。F7 也可切换窗口。
L3 + A／B重新居中／显示或隐藏游戏 UI
L3 + View／Menu第一人称／快捷键提示页

PS4／PS5：通过 Steam Input 或其他有效的 Xbox／XInput 映射，可使用相同快捷键。叉／圆／方块／三角对应 A／B／X／Y，L1／R1 对应 LB／RB，L2／R2 对应 LT／RT，Share／Create 对应 View，Options 对应 Menu。

1.1.0 新增实验性直连输入，支持 Sony DualShock 4、DualSense／Edge 的 USB 或蓝牙报告；连续两秒未成功读取 XInput 手柄时才使用。任何活跃 XInput 手柄都优先。重连或输入来源变化后先松开全部按键，并查看 VR → 鸣潮控制 → 手柄快捷操作 的状态。直连输入可开关 UEVR，但菜单操作仍需键盘／鼠标、XInput 映射或现有 VR 菜单控制。直连模式无法阻止游戏自身接收这些按键，因此快捷键也可能触发游戏动作；需要拦截组合键时优先使用 XInput 映射。未添加触控板／PS 键快捷键、震动或自适应扳机支持，实体 PS 手柄验证仍待完成。详见完整说明。

屏幕选项位于 VR → WuWa Controls → View modes and cutscenes（视图模式与过场）。过场构图修正默认开启。自动切换仍为实验功能且默认关闭：已报告的一段引擎内过场未触发，预渲染影片切换也未测试，请保留手动影院快捷键。

可选漫游、微缩视角与裸手演示

VR 控制器漫游（可选）→ 漫游输入每次启动默认关闭，需要 OpenXR。唤醒两侧 Quest 控制器、让游戏获得焦点，松开按键、扳机和握持键并让摇杆回中后启用输入；焦点丢失或重连后重复。

仅 VR 控制器使用槽位 0。VR + 跑步机／Xbox 槽位保留所选设备的移动输入，并添加 VR 按键和视角控制。在故障排查 → 手柄检查查看槽位，但编号不能独立识别 RealityRunner。第一人称是独立选项；这套漫游布局不包含完整战斗按键，详见漫游控制说明。

微缩视角需要 Native Stereo，世界比例变化也会放大头部位移；关闭后恢复普通比例。裸手／手指演示只显示骨架，没有抓取、碰撞或手势玩法。这些选项默认关闭，实机头显验收仍待完成。

遇到问题时

  • 启动卡住：点击停止等待。若未确认取消，打开故障排查 → 卡住的启动器进程 → 查找卡住的启动器进程，查看身份与可停止状态，选择目标后确认停止所选进程。默认不勾选任何进程；查看结果后再重试连接。
  • 窗口无法关闭：仅关闭启动器保留后台工作，不会解除启动锁。恢复工具不终止游戏、Steam、注入器或 VR 运行时；录制及运行时／配置修改仍受保护。
  • 找不到手柄：手柄检查只读取 XInput 槽位与 HidHide 信息，不修改设置。检测到槽位不等于游戏已收到按键；保留有意配置的跑步机／映射方案。
  • HUD 变扁：尝试 VR → WuWa Controls → Reset HUD aspect 并查看结果；该功能仍可能不可用。游戏允许时开关 ESC 菜单曾帮助恢复。L3 + B恢复被隐藏的游戏 UI。
  • 报告问题：使用复制诊断和报告问题，附上应用与 VR 包版本、具体经过及可用录像。
删除下载版本或卸载

空闲时使用故障排查 → 准备卸载，确认后清理已验证的下载，再去 Windows 设置 → 应用卸载。游戏、设置、备份、录像、当前 OpenXR 所用包及忙碌／无法验证的文件会保留，请查看清理报告。Windows 卸载也会尝试限时清理；重装不能代替停止卡住的进程。

录制与当前限制

底部开发工具打开所选包的网页工具，包含录制、测试记录及日志。录制支持 SteamVR 和内置模拟器，不支持 VDXR 或音频。分享前检查玩家名称及账号信息；参阅反馈指南。

用户已确认 1.0.10 在此前受影响的 Windows 11 Steam 电脑上通过模拟器启动成功。这不代表 1.1.0 的 PS4／PS5 或实体头显验收；这些检查仍待完成。

待解决问题包括场景／对话加载停顿、HUD 刷新不可靠、平面菜单背景移动、远处 NPC 边缘光不一致、武器／声骸子菜单反射，以及完整动画第一人称瞄准。部分菜单／过场可用手动单目影院暂时处理。可选边缘光抑制也会去掉近处角色原有高光，是临时方案而非着色器修复。模组保留游戏画质选择与自定义修改；只有指定升级流程会清理已识别的旧覆盖项。
