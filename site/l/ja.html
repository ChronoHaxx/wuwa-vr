始め方

  1. ZIP全体を通常のフォルダーに展開し、WuWa VR Launcher.exeを開きます。appとpythonフォルダーは隣に置いたままにしてください。Pythonの別途インストールは不要です。
  2. ヘッドセットを接続し、対応ソフトを起動します。シミュレーターを使う場合はゲームとインジェクターを終了し、「このパッケージのシミュレーターを使用」を選びます。システムのOpenXR切り替えにはWindowsの許可が必要で、次回起動時に反映されます。
  3. リスク説明に同意し、ビルドを選んで「適用して起動」を押します。注入のWindows許可に同意し、ゲームランチャーでプレイを押してください。確認済みなのは独立した公式ランチャーです。Steam/Epic版への注入は未確認です。
  4. L3 + R3でUEVR設定、L3 + BでHUDとメニューの表示切替、L3 + Aでリセンター、L3 + Menuで操作表、L3 + LBでHUD／マウスモードを切り替えます。ゲーム用ショートカットの前にUEVR設定を閉じてください。

Xbox の基本ショートカット

L3 / R3 はスティックの押し込みです。View は四角が重なったボタン、Menu は三本線です。LB + Y はゲーム本来の操作のままです。

快適さと復帰

HUD placement and visibility で視線追従 HUD を選び、大きさと距離を一緒に調整するか、任意のウィンドウに合わせます。L3 + B で非表示のメニューを戻し、L3 + A でリセンターできます。新しい付属設定では表が初期表示され、L3 + Menu で隠せます。既存の保存設定は保持されます。

未解決の点

使用するビルドに付属する設定に従ってください。Native Stereo Fix の初期値はリリースごとに異なります。新しいパッケージでは BUILD GUIDE.html に値を記載しています。両眼の反射・表示・照明の差や、完全アニメーション追従時の照準は検証中です。修正候補はすべての場面で確認済みではありません。ゲーム時間全体の停止機能はありません。
