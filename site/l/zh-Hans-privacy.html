隐私

本网站会统计使用情况，以便了解哪些指南有帮助、大家在哪里遇到困难。本网站不使用 Cookie，也不保存任何能识别你身份的信息。

统计哪些内容

打开了哪些页面、使用哪种语言；对“下载”以及 GitHub、YouTube 和 Ko-fi 链接的点击；指南读到了哪里；打开了哪些问题；快捷键搜索是否找到结果（绝不记录你输入的内容）；以及反馈表单的按钮。

如何统计

Cloudflare Web Analytics 统计页面浏览量，我们自己的小型计数器（同样运行在 Cloudflare 上）统计其余内容。为了统计每日访客数，你的 IP 地址和浏览器信息会与一个每天丢弃的随机密钥混合计算；你的 IP 地址从不保存。数据在 Cloudflare 上保留 3 个月后删除。我们只查看每日汇总。

绝不做的事

不投放广告，不跨网站跟踪，不录制屏幕，也不出售或分享数据。

你的选择

如果你的浏览器发送 Global Privacy Control 或 Do Not Track 信号，则不会统计任何内容。你也可以用下面的按钮在此浏览器上关闭统计。它只会在你的浏览器中保存一项设置，别无其他。

下载

GitHub 会统计每个发布文件的下载次数。我们每天复制一次这些总数。

WuWa VR 应用

该应用不发送任何使用数据。它只会连接 GitHub 检查更新并下载 VR 模组。

保存在你浏览器中的内容

如果你选择了语言和手柄按键名称，会保存你的选择，让下一个页面保持一致。这些信息从不离开你的浏览器。

其他网站

只有在你选择视频后，视频才会从 youtube-nocookie.com 播放。GitHub、YouTube 和 Ko-fi 有各自的隐私政策。
