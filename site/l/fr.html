Commencez dans votre langue

Un projet VR gratuit et non officiel de Wuthering Waves, créé par des fans. Gardez votre manette Xbox et adaptez la vue et le HUD à votre confort.

Les commandes principales du lanceur et ce guide sont traduits. Certaines descriptions de versions, les outils de développement et les erreurs restent en anglais. Les traductions sont provisoires ; ce choix ne change pas la langue du jeu ni d’UEVR.

Pour commencer

  1. Extrayez tout le ZIP dans un dossier normal, puis ouvrez WuWa VR Launcher.exe. Gardez les dossiers app et python à côté. Il n’est pas nécessaire d’installer Python.
  2. Connectez le casque et démarrez son logiciel. Pour utiliser le simulateur, fermez WuWa et l’injecteur, puis choisissez Utiliser le simulateur de ce paquet. Changer le runtime OpenXR du système demande une autorisation Windows et prend effet au prochain lancement.
  3. Lisez et acceptez l’avertissement, choisissez une version, puis cliquez sur Appliquer et lancer. Acceptez l’autorisation Windows pour l’injection et cliquez sur Jouer dans le lanceur du jeu. Le lanceur officiel autonome a été testé ; l’injection Steam/Epic reste non vérifiée.
  4. L3 + R3 ouvre UEVR. L3 + B affiche/masque le HUD et les menus ; L3 + A recentre ; L3 + Menu affiche les raccourcis ; L3 + LB bascule le mode HUD/souris. Fermez les réglages UEVR avant d’utiliser les raccourcis du jeu.

Raccourcis Xbox courants

L3 / R3 désigne une pression sur le stick. View est le bouton aux deux carrés ; Menu, celui aux trois lignes. LB + Y conserve l'action normale du jeu.

Confort et récupération

Dans HUD placement and visibility, choisissez un HUD qui suit le regard, ajustez sa taille et sa distance ensemble ou adaptez-le à la fenêtre facultative. L3 + B réaffiche un menu masqué ; L3 + A recentre. Le nouveau profil affiche l'aide par défaut : L3 + Menu la masque. Les choix déjà sauvegardés sont respectés.

Points encore à améliorer

Utilisez les réglages fournis avec votre version ; les valeurs par défaut de Native Stereo Fix varient selon la version. BUILD GUIDE.html les indique dans les nouveaux paquets. Les reflets, les différences de visibilité et d’éclairage entre les yeux et la visée avec animation complète restent en cours de test. Les correctifs candidats ne sont pas confirmés dans toutes les scènes. Il n’y a pas de pause globale du temps.

Gratuit, amateur et communautaire

Le site original, les guides et les éléments indépendants explicitement listés sont sous MIT. UEVR, les scripts communautaires et le contenu du jeu gardent leurs conditions : le mod entier n'est pas sous MIT. Forks et contributions sont bienvenus lorsque ces conditions le permettent.

Gardez l'accès gratuit, créditez les auteurs, partagez les améliorations et évitez la vente de repacks ou les forks payants. C'est une demande communautaire, pas une condition ajoutée à MIT : MIT autorise l'usage commercial et la vente.
