开始使用

  1. 使用你已安装的《鸣潮》，并连接 PCVR 头显。目前还没有公开下载；以下步骤适用于私下测试用的 WuWa VR Launcher 安装包。
  2. 将整个 ZIP 解压到普通文件夹，然后打开 WuWa VR Launcher.exe。它会在你的电脑上打开一个本地页面，不需要管理员权限。勾选风险确认框，选择版本（默认是作者实测过的版本），然后点击 Apply & launch。
  3. 启动模组需要 Windows 权限确认，然后在独立的官方启动器中点击开始游戏；这是此前正常运行的方式。新的便携包尚未完成实际游戏启动测试。Steam 商店版此前注入失败，尚未重新测试；Epic 版未经测试。支持 SteamVR / Steam Link 头显连接不代表支持 Steam 商店版游戏。请勿关闭 Windows 安全防护。
  4. 按 L3 + R3 打开 UEVR。在 VR > WuWa Controls 中，快捷键位于顶部，可选实验功能位于底部。关闭 UEVR 菜单后再使用游戏快捷键；切换模式后松开所有按键。

Xbox 常用快捷键

L3 / R3 表示按下摇杆。View 是双矩形键，Menu 是三横线键。LB + Y 保持游戏原有功能。

舒适度与恢复

在 HUD placement and visibility 中选择跟随视线的 HUD，一起调整大小与距离，或让它适配可选窗口。L3 + B 可恢复被隐藏的菜单；L3 + A 可重置视角中心。新提供的配置默认显示快捷键表，L3 + Menu 可隐藏。已有的个人设置会保留。

仍待完善的问题

请保持 Native Stereo Fix 关闭。第一人称冲刺与飞翼、部分角色切换、预览反射重复、NPC 标签仅在单眼出现等问题仍待完善。新选项是测试候选方案，不是通用修复。没有全局暂停时间功能。
