Build and testing notes

One grouped session

If you received a candidate ZIP, open its BUILD GUIDE.html. It identifies the included builds, actual supplied settings and grouped checks for launch, stereo, menus, controls, first person, recording and recovery. Report pass / fail / not tried together; no repeated diagnostic-only launches are requested.

The shared-frame candidate dated 28 Sep is a local test build. Its source and package checks have passed, but foliage, prop visibility, lighting, reflections and ultimate-end eye disagreement still need visual acceptance. Full-animation headset aiming remains experimental.

Checkpoint identities

6 Oct startup compatibility beta 1.1.1 (game 3.7): files, source and checksums, VR build steam-resize-1-1-1. The user confirmed 1.0.10 startup on the previously affected Windows 11 Steam simulator PC, and 1.1.0 through Kuro on the owner's PC. The owner's 1.1.0 Steam route crashed. Version 1.1.1 repairs the resize recursion found in that crash dump; controlled graphics and launcher tests pass, but this repair still needs real Steam and headset testing.

The report does not establish Windows 11 as the cause. The retained cinematic correction was accepted in a simulator replay with matching letterbox heights; headset comfort remains pending. Automatic cinema stays off and unverified. See the release receipt for build/package checks. Previous 6 Oct beta and 26 Sep beta remain historical checkpoints. Keep the build name, timestamp and backend hash with a report.
