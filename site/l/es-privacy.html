Privacidad

Este sitio cuenta cómo se usa para saber qué guías ayudan y dónde se atasca la gente. No usa cookies ni guarda nada que te identifique.

Qué se cuenta

Qué páginas se abren y en qué idioma; los clics en Descargar y en los enlaces a GitHub, YouTube y Ko-fi; hasta dónde se lee la guía; qué preguntas se abren; si el buscador de atajos encontró algo (nunca lo que escribiste); y los botones del formulario de comentarios.

Cómo

Cloudflare Web Analytics cuenta las visitas a cada página y un pequeño contador propio, también en Cloudflare, cuenta el resto. Para contar los visitantes diarios, tu dirección IP y tu navegador se mezclan con una clave aleatoria que se descarta cada día; tu dirección IP nunca se guarda. Los datos se quedan en Cloudflare 3 meses y luego se borran. Solo se miran los totales diarios.

Nunca se hace

Nada de publicidad, seguimiento entre sitios, grabación de pantalla ni venta o cesión de datos.

Tú decides

Si tu navegador envía Global Privacy Control o Do Not Track, no se cuenta nada. También puedes desactivar el recuento en este navegador con el botón de abajo. Guarda un único ajuste en tu navegador y nada más.

Descargas

GitHub cuenta cuántas veces se descarga cada archivo de una versión. Copiamos esos totales una vez al día.

La aplicación WuWa VR

La aplicación no envía datos de uso. Solo se conecta a GitHub para buscar actualizaciones y descargar el mod de VR.

Guardado en tu navegador

Tu idioma y los nombres de botones del mando, si eliges alguno, para que la siguiente página coincida. Nunca sale de tu navegador.

Otros sitios

Los vídeos se reproducen desde youtube-nocookie.com solo cuando eliges uno. GitHub, YouTube y Ko-fi tienen sus propias políticas de privacidad.
