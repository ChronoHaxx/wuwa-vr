Build and testing notes

One grouped session

If you received a candidate ZIP, open its BUILD GUIDE.html. It identifies the included builds, actual supplied settings and grouped checks for launch, stereo, menus, controls, first person, recording and recovery. Report pass / fail / not tried together; no repeated diagnostic-only launches are requested.

The shared-frame candidate dated 28 Sep is a local test build. Its source and package checks have passed, but foliage, prop visibility, lighting, reflections and ultimate-end eye disagreement still need visual acceptance. Full-animation headset aiming remains experimental.

Checkpoint identities

Current beta 1.2.3 (game 3.7): files, source and checksums, VR build ui-layout-1-2-3. The owner played 1.2.0 in the headset (Valve Index controllers with a Bigscreen Beyond; a Meta Quest Pro with a Reality Runner treadmill), 1.2.1 in the headset with the Kuro launcher copy of the game, and an earlier 1.2.3 test build in the headset (SteamVR) with the Kuro launcher copy. The final 1.2.3 test builds were tested by the owner on the OpenXR simulator with both the Steam copy and the Kuro launcher copy: menus, the mouse and the controller cursor in the 16:9 and taller layouts, story pictures and story scenes, the character screen and the translations; on the Steam copy the UI redirect starts and the stereo fixes pass their code checks. The 1.2.3 release build has not been played in a headset yet. In Move menu the VR thumbstick does not change the distance yet (use Menu distance). Many dialogue close-ups still sit wider than the 2D shot.

The retained cinematic correction was accepted in a simulator replay with matching letterbox heights; headset comfort remains pending. Automatic cinema stays off and unverified. See the release receipt for build/package checks. Previous beta and 26 Sep beta remain historical checkpoints. Keep the build name, timestamp and backend hash with a report.
