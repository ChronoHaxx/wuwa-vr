安装后只需三步

运行 WuWa-VR-Setup.exe 并打开 WuWa VR，启动器会引导你完成其余步骤。首次安装会下载 VR 模组，无需 Python 或其他工具。

  1. 01

    找到《鸣潮》

    选择 Steam 版或官方库洛启动器版游戏。你的选择会被保存。暂不支持 Epic。

  2. 02

    安装 VR

    阅读账号风险说明，确认游戏版本后安装。更新会保留你的设置和备份。

  3. 03

    头显或模拟器

    启动头显软件，或选择内置模拟器。然后选择“以 VR 模式启动”，并接受 Windows 权限提示。

为游玩而生，不只是看看

  • 立体 VR 与头部追踪

    在 OpenXR 头显中呈现真实景深。菜单和 HUD 依然可用，界面可以移动、缩放或隐藏。

  • 手柄优先

    支持 Xbox 手柄和实验性的 PlayStation 快捷键，按 L3 + Menu 可在 VR 中查看快捷键表。

  • 第一人称身体

    隐藏头部后能看到角色的双手和服装。可选完整动画跟随，并内置舒适模式。

  • 自由视角

    自由镜头、无人机、飞机和特技视角，适合探索和截图。实验性功能。

  • 6DOF 窗口

    可选的窗口模式，把游戏画面放进你的房间。改编自 Elliott Tate 的作品。

  • 双眼一致

    远处的树木、物件和间接光照在两只眼睛中保持一致，整个世界浑然一体。

常见问题

支持哪些头显？

WuWa VR 使用 OpenXR。已在 Quest Pro 上通过 SteamVR 游玩；其他 OpenXR 头显应该可以使用，但尚未验证。内置模拟器可以让你在普通屏幕上试用。

Steam、库洛启动器还是 Epic？

支持 Steam 和官方库洛启动器。暂不支持 Epic。

账号会被限制吗？

有可能。模组会注入游戏，反作弊可能会检测到。库洛游戏没有批准本模组。安装前请阅读风险说明。

Windows 对安装程序发出警告，这正常吗？

安装程序没有代码签名，所以 SmartScreen 可能会警告。请只从项目的 GitHub 发布页下载，并核对 SHA-256 校验值。切勿关闭杀毒软件或反作弊。

怎么更新？

应用会检查自身更新，并在重启前询问你。VR 包在步骤 02 中单独更新，也可以回退到之前安装的版本。

会修改游戏文件吗？

不会。启动器不会改动游戏文件；VR 模组在启动时注入。

怎么卸载？

先在应用中使用“故障排查 → 准备卸载”，再到 Windows 设置 → 应用中移除 WuWa VR。设置、备份和录像会保留，除非你手动删除。

免费吗？

免费。这是免费的粉丝项目，启动器以 MIT 许可开源。在 Ko-fi 上支持完全自愿，不附带任何保证。

已知限制

  • 部分电脑上 Steam 启动仍会失败，修复正在测试中。官方库洛启动器路线测试最充分。
  • 部分场景和对话加载可能卡住，平面菜单背后可能出现移动的背景。
  • HUD 比例刷新不稳定；部分 NPC 光照、反射和雾效仍需测试。
  • 自动过场切换为实验性功能，默认关闭；预渲染影片也未测试。
