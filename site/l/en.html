Install, then three steps

Download beta installer · Windows EXE Release notes & source

1.0.0 beta · WuWa 3.7 · Windows x64

Advanced: portable ZIP · Previous beta · 1 October

Run WuWa-VR-Setup.exe to install WuWa VR for your Windows user, then open the WuWa VR shortcut. This small installer does not include the VR mod: the first Install VR needs internet to download about 54 MB. No separate Python installation is needed.

  1. 01 · Game. Check the detected official game launcher, or choose its location. You need your own copy of Wuthering Waves.
  2. 02 · Install VR. Read and accept the account-risk notice, then install the selected VR version. Existing settings and backups are kept.
  3. 03 · Headset or simulator. Start your headset software and check the displayed runtime, or deliberately choose the simulator. Select Launch in VR, accept the Windows permission prompt, then press Play in the official game launcher.

In game, L3 + R3 opens UEVR settings. Custom options are under VR → WuWa Controls. L3 + A recenters and L3 + B shows or hides the game UI.

Use at your own risk. This unofficial mod injects into the game; anti-cheat may restrict or ban an account. It is not approved by Kuro Games.

Two kinds of update

Open 02 → Versions & updates → Check updates. Desktop app: choose Update launcher to download and verify the update; this does not restart the app. When it is ready, close the game and injector, stop recording and finish other operations, then choose Restart to update and confirm. Installing or updating the desktop app preserves your selected VR package. VR package: in step 02 choose beta-2026-10-04-launcher and install it, or select it if already installed, to use npc-rim-20261004 (formerly the private NPC-rim candidate). Your settings, backups, logs and recordings stay in their existing data folders. Older VR packages remain available for rollback.

Choosing a simulator or restoring the headset runtime changes the system OpenXR runtime and may ask for Windows permission. Close the game and injector first. Opening or updating the app does not select the simulator for you.

What this beta changes

The owner reports that 2D-screen brightness and the ultimate camera are corrected. The new NPC rim option still needs physical-headset checking; a fresh-PC installation is also unverified.

Suppress mismatched NPC rim lighting is under VR → WuWa Controls and starts off. It suppresses the toon-rim effect that produced extra bright contours in the tested NPC scene. It also removes that intended effect from nearby characters that use it. Turning it off restores the prior value if the workaround still owns it. The underlying stereo rendering fault is unresolved.

This is a beta for game 3.7, not a claim that every scene is fixed. Weapon/Echo submenu reflections and full-animation first-person aiming remain open. The standalone official launcher is the tested route; Steam/Epic game injection remains unverified.

Advanced: portable ZIP

The portable ZIP is an advanced fallback: extract the whole archive, keep its app and python folders together, and open WuWa VR Launcher.exe. It uses the older browser interface and does not install or self-update the desktop app. The installer is the recommended starting point.

Everyday Xbox controls

L3 / R3 mean pressing the sticks. View is the two-squares button; Menu is the three-lines button. LB + Y stays the game's normal action.

L3 + R3Open / close UEVR settings
L3 + BShow / hide game UI, including menus
L3 + ARecenter view / portal
L3 + MenuShow / hide the shortcut sheet
L3 + LBToggle HUD / mouse adjustment, then release (newer candidate builds)
L3 + ViewFirst person on / off
Double R3Freecam on / off
L3 + RBGame / fixed camera

Comfort and recovery

In HUD placement and visibility, choose a following HUD, adjust size and distance together, or fit it to the optional portal. L3 + B restores a hidden menu. L3 + A recenters your view. The sheet starts enabled in the new supplied profile; L3 + Menu hides it. Existing saved choices are respected.

What still needs work

Use the settings supplied with your build; Native Stereo Fix defaults differ between releases. BUILD GUIDE.html in newer packages lists those values. Reflections, visibility and lighting differences between eyes, and full-animation aiming remain under test. Candidate fixes are not confirmed for every scene. No global time pause is implemented.
