WHAT IS ALREADY CONFIRMED
The owner confirmed the simulator replay on private screen-comfort-r1. Sampled
frames from the latest 68-second recording show matching cinematic letterbox
heights across eyes. Cinematic framing defaults on in this release and keeps the
authored letterbox. This is not headset comfort or all-scene acceptance.
Earlier accepted foliage, indirect lighting, main Resonators reflection, ultimate
camera and headset 2D-brightness corrections are retained.

ONE GROUPED HEADSET CHECK — record Pass / Fail / Blocked / Not tested for each.
1. Replay a known cinematic in normal immersive VR. Compare camera framing,
   letterbox heights and movement in both eyes; then check the return to gameplay.
   Record the scene and mode if there is disagreement or a long loading stall.
2. Manual screens: close UEVR and HUD/mouse adjustment. Fully hold LT + RT first,
   then click R3 for mono theatre (identical scene + HUD in both eyes). Release
   everything before repeating to return. Separately use LT + RT then hold L3
   for 0.8 seconds for a screen with stereo depth. Check brightness, depth direction
   and switching back. Automatic cinema stays off for this comparison.
3. Menu/dialogue recovery: check HUD proportions after returning. Try Reset HUD
   aspect and read the result; unavailable is not a pass. ESC open/close has helped
   when accessible. If the background moves behind a flat menu, use manual mono
   theatre and record the result. Neither workaround establishes a loading-stall fix.
4. Brief regression: Xbox movement, a tested ultimate return, near/far foliage,
   L3+LT/F7 portal and L3+RT diorama should retain their earlier behavior. Release
   controls after focus changes. Optional Quest walking/hand demos need separate
   physical acceptance only if you choose to use them; no full repeat is required.
5. End normally and confirm the selected package/settings remain. Keep the prior
   beta for rollback. Include release/backend identity and runtime in any report.

OPEN LIMITS
Automatic cinema is experimental and off by default. It did not activate for the
latest reported in-engine scene; actual prerendered movie switching is untested.
Long scene/dialogue stalls, HUD refresh and flat-menu background motion remain
open. NPC rim suppression remains an optional workaround, off by default: it also
removes intended nearby rim light. Underlying NPC stereo lighting, Weapon/Echo
submenu reflections, some VFX and full-animation first-person aiming remain open.
Fresh-PC installation, Steam/Epic injection and optional controller/hand features
are not established by simulator, component or package checks.

已有证据：作者确认私测 screen-comfort-r1 的模拟器回放改善；最新 68 秒录像抽样
中双眼过场黑边高度一致。构图修正默认开启并保留原有黑边，尚不代表头显舒适度或
所有场景通过验收。保留此前已接受的植被、间接光照、共鸣者主页面反射、大招镜头
及头显二维亮度修正。

统一头显检查——每项记录通过／失败／受阻／未测试。
1. 普通沉浸 VR 中回放熟悉过场，检查两眼构图、黑边、移动及返回游戏；记录场景、模式和停顿。
2. 手动屏幕：关闭 UEVR 与 HUD／鼠标调整，先按住 LT + RT，再点击 R3 切换单目影院
   （两眼相同场景与 HUD），松开全部按键后重复返回。另测 LT + RT 后按住 L3 0.8 秒
   的立体屏幕，检查亮度、深度方向及返回。此对比保持自动影院关闭。
3. 检查菜单／对话 HUD 比例。尝试 Reset HUD aspect 并读结果；不可用不能算通过。
   游戏允许时 ESC 开关曾帮助恢复。平面菜单背景移动时可暂用单目影院并记录结果；
   这些方式不是已确认的加载停顿修复。
4. 简短回归：Xbox 移动、大招返回、远近植被、L3+LT/F7 空间窗口、L3+RT 微缩。
   失焦返回需先松开按键。可选 Quest 漫游／裸手演示仅在想使用时另做实机检查。
5. 正常退出后确认已选包与设置保留，留旧版以便回退；反馈附上版本、后端与运行时。

已知限制：自动影院是实验功能，默认关闭；最近引擎内过场未自动切换，真正的预渲染
影片未测试。场景／对话停顿、HUD 刷新和平面菜单背景移动仍未解决。
NPC 轮廓光抑制默认关闭，也会移除近处原有轮廓光，不是底层立体修复。
NPC 立体光照、武器／声骸子菜单反射、部分特效、完整动画第一人称瞄准仍有问题。
全新电脑安装、Steam／Epic 注入及可选手柄／裸手功能不能由模拟器或安装包检查证明。
