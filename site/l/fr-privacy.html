Confidentialité

Ce site compte la façon dont il est utilisé, pour savoir quels guides aident et où les gens bloquent. Il n'utilise aucun cookie et n'enregistre rien qui vous identifie.

Ce qui est compté

Les pages ouvertes et leur langue ; les clics sur Télécharger et sur les liens vers GitHub, YouTube et Ko-fi ; jusqu'où le guide est lu ; les questions ouvertes ; si la recherche de raccourcis a trouvé quelque chose (jamais ce que vous avez tapé) ; et les boutons du formulaire de retours.

Comment

Cloudflare Web Analytics compte les pages vues, et un petit compteur à nous, lui aussi sur Cloudflare, compte le reste. Pour compter les visiteurs par jour, votre adresse IP et votre navigateur sont mélangés à une clé aléatoire jetée chaque jour ; votre adresse IP n'est jamais enregistrée. Les données restent 3 mois chez Cloudflare, puis sont supprimées. Seuls les totaux par jour sont consultés.

Jamais fait

Pas de publicité, pas de suivi entre sites, pas d'enregistrement d'écran, ni vente ni partage de données.

Votre choix

Si votre navigateur envoie Global Privacy Control ou Do Not Track, rien n'est compté. Vous pouvez aussi désactiver le comptage sur ce navigateur avec le bouton ci-dessous. Il enregistre un seul réglage dans votre navigateur, rien d'autre.

Téléchargements

GitHub compte combien de fois chaque fichier de version est téléchargé. Nous copions ces totaux une fois par jour.

L'application WuWa VR

L'application n'envoie aucune donnée d'utilisation. Elle contacte GitHub uniquement pour chercher les mises à jour et télécharger le mod VR.

Enregistré dans votre navigateur

Votre langue et les noms de boutons de manette, si vous en choisissez, pour que la page suivante corresponde. Cela ne quitte jamais votre navigateur.

Autres sites

Les vidéos ne se lisent depuis youtube-nocookie.com qu'une fois que vous en choisissez une. GitHub, YouTube et Ko-fi ont leurs propres politiques de confidentialité.
