License and sharing

This is a free, unofficial fan project. Our original independent work uses MIT. Each upstream component keeps its own terms.

Open-source desktop launcher

The desktop manager source is MIT open source under its own licence. The mod source changes are public, with pinned build instructions. Downloaded mod components keep their own terms; public source availability does not make the combined package uniformly open source.

What our MIT grant covers

Original text in the README, support/contribution/credit pages and player docs; original website HTML, CSS, JavaScript and translations; the abstract mark; the site generators and checks; original issue templates and website export README/workflow. Quoted third-party material is excluded. Preserve copyright and license notices.

What it does not cover

UEVR backend, native adaptations/patches, community scripts and adaptations, game code/assets/screenshots/trademarks, and other owners' work. The generated controller illustration is not an official Xbox asset or an assertion of exclusive copyright. The whole mod is not MIT. See component credits; public combined-mod redistribution remains pending clarification.

A community request

Please keep access free, credit creators, share improvements and avoid paid repacks or paywalled forks. This is a community request, not an extra MIT condition: MIT permits commercial use and sale. MIT does not require forks to publish source. We encourage freely accessible improvements and contributions where each component's terms allow.

Optional support

There is no obligation to donate. Please do not donate if you expect permanent support, updates, personal help or guaranteed compatibility. This is a spare-time hobby and I may pause or stop. Contributions support the work as it is, with nothing owed in return. A GPU upgrade would help local open-weight model experiments and modded VR.
